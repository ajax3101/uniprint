## Известные ограничения

- Репозиторий без коммитов и содержит неотслеживаемые файлы; точное происхождение их исходного состояния неизвестно.
- Нет данных о реальном парке оборудования, сети, серверах печати, IdP, хостинге, резервировании и правилах университета.
- Возможности мониторинга описаны по стандартам и документации, но не проверены на принтерах учреждения.
- Юридический статус заявок/согласований, законное основание и сроки обработки персональных данных не определены.
- Не реализованы позиции/слоты картриджей в принтере, provenance показаний, полный юридически оформленный процесс списания, штрихкод, отчёты и настраиваемые маршруты.
- Реальная аутентификация/SSO отсутствует; API fail-closed вне явно включённого локального режима разработки.
- Для frontend выбраны React 19.3, Vite 6.4.5, TypeScript 7 по проверенной локальной сборке; Vite 8 из кэша не удалось запустить из-за ошибки нативного Rolldown binary.

## Следующий шаг

Следующий шаг разработки: подготовить конкурентный прогон на отдельной PostgreSQL тестовой базе для параллельной выдачи и установки. Далее — инвентаризация и штрихкод, затем отчёты. До подключения IdP, сбора телеметрии, развёртывания и юридически значимого согласования получить соответствующее отдельное решение университета.
